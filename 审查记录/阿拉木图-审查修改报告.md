## 三、逐效果核验

### 1) 额外最大血量

- `CvUnit.cpp:15239` — `CvUnit::GetMaxHitPoints()` 叠加 `GetCSUAKillMaxHpBonus()`。
- `CvUnit.cpp:19949` — `CvUnit::GetCSUAKillMaxHpBonus()`：遍历 `CityStateUAEffect_KillMaxHpByPromotion` 配置行，单位持对应晋升且缓存盈余 > 0 时累加 `Kills × Surplus × Percent / 100`。
- 朋友行仅 HITANDRUN，故朋友的重骑兵天然不享受，与设计一致。

### 2) 掠夺中立商路

- `CvUnit.cpp:9769-9779` — `CvUnit::canPlunderTradeRoute()` 在 `MOD_SP_UNIQUE_CITYSTATE` 下额外放行 `pCSUA->IsCanPillageNeutralTradeRoute()`（来自 `CanPillageNeutralTradeRoute=true`）。

### 3) 掠夺金 / 经验 / 红脸

- `CvTradeClasses.cpp:3839-3873` — `CvPlayerTrade::PlunderTradeRoute()`：
  - 金：`200 × (GetCurrentEra()+1)`，**对所有掠夺生效**（含敌方）。
  - 经验：15，**对所有掠夺生效**（`MOD_API_EXTENSIONS` 下）。
  - 红脸：仅在 `!GET_TEAM(m_pPlayer->getTeam()).isAtWar(eOwningTeam)`（中立）且被掠方 `isMajorCiv()` 时累加。
- 与"金/经验全部掠夺生效，仅红脸限中立"的口径完全吻合。

### 4) 红脸状态机

- 成员：`CvDiplomacyAI::m_paiCSUAPlunderedNeutralTradeRoute`（`short × MAX_MAJOR_CIVS`）。
- 初始化清零：`CvDiplomacyAI.cpp:919`（Reset）。
- 每回合衰减 1、下限 0：`CvDiplomacyAI.cpp:2045-2046`（DoTurn）。
- 累加时钳非负：`CvDiplomacyAI.cpp:23654`（ChangeCSUAPlunderedNeutralTradeRoute）。
- 意见集成：`CvDiplomacyAI.cpp:2574`（GetMajorCivOpinionWeight）。
- Lua 展示：`Lua/CvLuaPlayer.cpp:11944`（GetOpinionTable，`TXT_KEY_DIPLO_CSUA_PLUNDERED_TRADE_ROUTE`）。
- 序列化：`MOD_SERIALIZE_READ_ARRAY(164, ...)`（`CvDiplomacyAI.cpp:1604`）/ `MOD_SERIALIZE_WRITE_ARRAY(...)`（`CvDiplomacyAI.cpp:1839`）。

### 5) 15 马匹发放

- 走 `CvMinorCivAI::DoUpdateAlliesResourceBonus`，**只对盟友**发放；朋友无此项，与"盟友额外提供 15 马匹"一致。
- `getNumResourceAvailable(res, true)` 含 `getResourceFromMinors`，故盟友自身也吃到这 15 匹带来的加成。

## 五、本轮修改清单

### M1 — 血量非负钳制（F3）

`CvGameCoreDLL_Expansion2/CvUnit.cpp:15252-15256`

```cpp
int CvUnit::GetCurrHitPoints() const
{
    VALIDATE_OBJECT
    // Max HP is not monotonic: losing a promotion (or, for Almaty, spending surplus strategic resources)
    // can shrink the cap below the damage already taken. Clamp at 0 so a shrunken cap never yields a
    // negative current HP; setDamage already expects this value to be non-negative.
    int iCurr = GetMaxHitPoints() - getDamage();
    return (iCurr > 0) ? iCurr : 0;
}
```

### M2 — 盈余马匹每回合缓存、击杀数实时（F4）

- `CvGameCoreDLL_Expansion2/CvCityStateUAClasses.h:66-71` — `KillMaxHpByPromotionEntry` 增字段：

```cpp
struct KillMaxHpByPromotionEntry {

    int m_iPercent;
```

- `CvCityStateUAClasses.h:1151` — 声明 `void CacheKillMaxHpSurplus();`
- `CvCityStateUAClasses.cpp:3226-3237` — 实现：

```cpp
void CvPlayerCityStateUA::CacheKillMaxHpSurplus()
{
    for (size_t i = 0; i < m_vKillMaxHpByPromotion.size(); i++)
        m_vKillMaxHpByPromotion[i].m_iCachedSurplus = 0;
    if (!m_pPlayer) return;
    for (size_t i = 0; i < m_vKillMaxHpByPromotion.size(); i++)
        m_vKillMaxHpByPromotion[i].m_iCachedSurplus =
            m_pPlayer->getNumResourceAvailable((ResourceTypes)m_vKillMaxHpByPromotion[i].m_iResource, true);
}
```

- `CvGameCoreDLL_Expansion2/CvPlayer.cpp:20278` — 在 `RefreshCSAllUAEffects()` 内调用 `m_pCityStateUA->CacheKillMaxHpSurplus();`
- `CvUnit.cpp:19949-19974` — `GetCSUAKillMaxHpBonus()` 改读 `vEntries[i].m_iCachedSurplus`；`GetTotalKills()` 保持实时。

> 缓存刷新点只有 `RefreshCSAllUAEffects()` 一个调用方（`CvPlayer.cpp:20178`），该函数每回合及盟友/朋友变更时都会跑，故盈余最多滞后一回合，符合"伪即时"要求。
