# 奢侈品衰减时代 · 实现计划

> 对应设计稿：《奢侈品衰减时代.txt》。本文档将衰减机制落实到 DLL（MPDLL 仓库）与数据（SP 仓库）两处，并用独立 OPT 开关控制运行。

## 一、机制

1. 给 `Resources` 表新增一列 `HappinessDecayEra`（TEXT，引用 `Eras(Type)`），记录该普通奢侈品的「所属时代」。
2. 世界时代超过该资源所属时代后，每超一个时代，其提供快乐 -1，最低降到 1。
3. **世界时代** = 所有存活队伍时代的算术平均值（`CvGame::getCurrentEra()`，见 `CvGame.cpp:4458`），与 SP 经济援助机制的「世界时代」语义一致，**并非某个玩家的时代**（`CvPlayer::GetCurrentEra()` 是玩家/队伍时代）。
4. 独立 OPT 开关 `LUXURY_ERA_DECAY` 控制整段逻辑运行。
5. 经久不衰的资源（14 个）不设置 `HappinessDecayEra`（保持 NULL → `NO_ERA`），永不衰减。

## 二、时代映射

| 设计稿（1-based） | EraType 字符串 | DLL 索引（0-based） |
|---|---|---|
| 中古(3) | `ERA_MEDIEVAL` | 2 |
| 启蒙(4) | `ERA_RENAISSANCE` | 3 |
| 工业(5) | `ERA_INDUSTRIAL` | 4 |

衰减判定 `getCurrentEra() > eDecayEra`，即「过了所属时代」才触发，每超 1 时代 -1。

### 3.6 CvGame.h / CvGame.cpp — 世界时代缓存

`getCurrentEra()` 每次遍历 MAX_TEAMS(64) 个队伍，而 `GetHappinessFromLuxury` 调用频繁，改为按游戏回合缓存。

- `CvGame.h` 成员区（`m_iEconomicAidWorldEra` 附近，line 724 后）加：
  ```cpp
  mutable EraTypes m_eCurrentEraCache;
  mutable int m_iCurrentEraCacheTurn;
  ```
- `CvGame.h` 公开区（`GetEconomicAidWorldEra` 附近，line 156 后）加声明：
  ```cpp
  EraTypes getCurrentEraCached() const;
  ```
- `CvGame.cpp` 构造函数（line 114 附近，`m_iEconomicAidWorldEra(1)` 后）加初始化：
  ```cpp
  , m_eCurrentEraCache(NO_ERA)
  , m_iCurrentEraCacheTurn(-1)
  ```
- `CvGame.cpp` 实现（`getCurrentEra` 之后，line 4482 后）加：
  ```cpp
  EraTypes CvGame::getCurrentEraCached() const
  {
      if (m_iCurrentEraCacheTurn != getGameTurn())
      {
          m_eCurrentEraCache = getCurrentEra();
          m_iCurrentEraCacheTurn = getGameTurn();
      }
      return m_eCurrentEraCache;
  }
  ```

> 用 `mutable` + `const` 保证在 `GetHappinessFromLuxury`（const）里可调用；缓存为纯派生数据，turn 初始 `-1`，读档后首次调用自动重算，不序列化、DLL 版本号（164）不变。

### 3.7 CvPlayer.cpp — 衰减逻辑

`GetHappinessFromLuxury`（line 14006），在 `int iBaseHappiness = pkResourceInfo->getHappiness();` 之后、联赛禁运检查之前插入：

```cpp
		// Luxury era decay: once the world era passes the resource's decay era, each excess era lowers happiness by 1 (floor 1)
		if (MOD_LUXURY_ERA_DECAY)
		{
			EraTypes eDecayEra = pkResourceInfo->getHappinessDecayEra();
			if (eDecayEra != NO_ERA && GC.getGame().getCurrentEraCached() > eDecayEra)
			{
				iBaseHappiness = std::max(1, iBaseHappiness - (GC.getGame().getCurrentEraCached() - eDecayEra));
			}
		}
```

> 放在联赛禁运之前，确保被禁运资源仍为 0，不会被 `std::max(1,…)` 复活成 1。

## 六、注意事项

1. **存档兼容**：`CvResourceInfo` 是 DB 加载的静态数据，新增字段无需 `MOD_SERIALIZE` 版本门控，DLL 版本号（164）不变。
2. **注释语言**：CIV5MPDLL 仓库代码注释必须英文（VC9 按 GBK 解析，中文注释会编译报错）。
3. **PCH 缓存**：改了 `CvInfos.h` 后，编译前需清理 `BuildTemp/VS2022_CvGameCore_Expansion2ReleaseWin32` 目录强制全量重建。
4. **行尾格式**：编辑各文件时保持原有 LF/CRLF 不变。
5. **世界时代 vs 玩家时代**：用 `GC.getGame().getCurrentEraCached()`（每回合缓存的平均时代），不是 `GetCurrentEra()`（玩家时代）。
6. **城邦高级奢侈品**：它们作为新资源若未设置 `HappinessDecayEra`，自然不衰减，符合「无衰减时代」设计，无需额外处理。
7. **UI 无需改动**：SP 顶部快乐 UI（TopPanel.lua）已全部走 `GetHappinessFromLuxury`/`GetHappinessFromResources`，衰减放在 DLL 内部会自动显示衰减值，其他 mod 的 UI 同样自动兼容；外交交易 tooltip（原版 ResourceTooltipGenerator.lua 读静态 `Happiness`）显示的是资源基础属性，经确认不改。
