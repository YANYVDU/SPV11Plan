# 王牌特工（第 4 级间谍）最终设计方案

> 基于 [王牌间谍.txt](王牌间谍.txt) 设计整理，补充代码落点、难度分级与实现要点。
> 前置：C++ 侧新增 `SPY_RANK_MASTER_SPY` 枚举（=3）、`GetSpyRankName` 返回 `TXT_KEY_SPY_RANK_3`、UI 按"方案一"金色染色。

## 一、定位与晋升途径

**定位**：间谍毕业形态（第 4 级），全队巅峰。比前 3 级（线性数值增强）多出"质变"能力。

**晋升途径（唯一）**：特级特工须**同时满足三线成就**后自动转化，不能通过其他途径升级：
1. 成功偷窃过科技
2. 成功击杀过他国间谍（反间谍击杀 / 政变击杀）
3. 成功操纵过城邦政变

实现要点：
- 新增 3 个跟踪成员变量（如 `m_bHasStolenTech` / `m_bHasKilledSpy` / `m_bHasCoupSuccess`），按 MPDLL 规则用 `MOD_SERIALIZE` 版本门控序列化。
- 触发点：偷科技成功（[CvEspionageClasses.cpp:773](CvEspionageClasses.cpp#L773)）、击杀结算（KILLED 档 [CvEspionageClasses.cpp:587](CvEspionageClasses.cpp#L587)）、政变成功处。
- `LevelUpSpy` 改为条件判定（满足三线成就才升第 4 级）。

## 三、关键实现要点

### C 政变影响力差值减半
政变公式（[CvEspionageClasses.cpp:2283-2364](CvEspionageClasses.cpp#L2283-L2364)）：
```
iDeltaInfluence = 盟友影响力 − 我的影响力（×100）
倍率 = 盟友查表值 − 我方查表值 + 3.0（无盟友间谍 ×0.5）
成功率% = 100 − (影响力差 × 倍率) / 100   [0, 85]，CSUA 可超 85
```
王牌时 `iDeltaInfluence /= 2` 即可，政变成功率显著提升。

### F 政变必定失败
- 语义：我方派王牌反间谍驻守**己方盟友城邦**，敌方对该城邦发动政变 → 强制失败（成功率=0）。
- 与 CSUA 政变加成（[:2366-2374](CvEspionageClasses.cpp#L2366-L2374)）不同：那是攻方加成，F 是守方压制，注意放对分支。
- 需要定位政变结算函数（盟主变更处理处），失败时给通知。

### G 金蝉脱壳
反间谍判定掷骰 0-300 三档：`<100` 仅察觉、`<200` 识别身份、`≥200` 击杀。王牌攻方被判定时 -100，最差只被识别、几乎不会被杀。

### H 全国可叠加
```
iSpyResult += (全国反间谍王牌数) × 10
```
需新增辅助统计：遍历我方间谍列表，`SPY_STATE_COUNTER_INTEL && rank==SPY_RANK_MASTER_SPY`。与 559 行本城 `rank*30` 叠加。

### J 王牌外交官
- "外交官" = `SCHMOOZE` 状态（建立联系后驻留，[CvEspionageClasses.cpp:887](CvEspionageClasses.cpp#L887)）。
- 选票：`GetExtraVotesPerDiplomat` 原版固定 1，按派驻外交官 rank 给 3（需按国区分，不能全局 +3/外交官）。
- 移民 +100%：需找到外交官对"移民速度"的加成逻辑（可能位于政策/移民处理），按 rank 扩展；若原版无此挂钩，需新增。

### K 投票承诺 -80%
```
// CvDealAI.cpp GetVoteCommitmentValue, bFromMe == false 分支
if (GetPlayer()->GetEspionage()->HasMasterSpyDiplomatVisitingThem(eOtherPlayer))
    iValue = iValue * 20 / 100;   // -80%
```
配套新函数 `HasMasterSpyDiplomatVisitingThem`：复用 [CvEspionageClasses.cpp:2883](CvEspionageClasses.cpp#L2883) `IsMyDiplomatVisitingThem`，取到派驻间谍 index 后检查 `m_eRank == SPY_RANK_MASTER_SPY`。

### L 肃贪（驻守本国 → 全国腐败 -5% / 可叠加）
腐败系统已有"驻守间谍减**本城**腐败"机制（[CvCity.cpp:24683](CvCity.cpp#L24683)：新手 -33% / 特工 -67% / 特级 -100%，王牌落入 -100% 兜底与特级相同）。L 为**全局**新增维度，两者叠加不冲突——正好补上王牌超越特级的差异点。
- 触发：王牌处于 `SPY_STATE_COUNTER_INTEL`（反间谍）即算"驻守本国"，无论驻守哪座己方城市。
- 可叠加：每有 1 个王牌反间谍，全国腐败 -5%（线性累加）。
- 实现：`CalculateTotalCorruptionScore` 的 modifier 段（[CvCity.cpp:24600-24612](CvCity.cpp#L24600-L24612)）加一行，并新增成员函数：
```cpp
modifier += CalculateCorruptionScoreModifierFromMasterSpy();  // 加在 modifier 段

int CvCity::CalculateCorruptionScoreModifierFromMasterSpy() const
{
    CvPlayerAI& owner = GET_PLAYER(getOwner());
    auto* espionage = owner.GetEspionage();
    if (espionage == nullptr) return 0;
    int iCount = 0;
    for (const auto& spy : espionage->m_aSpyList)
    {
        if (spy.m_eRank == SPY_RANK_MASTER_SPY && spy.m_eSpyState == SPY_STATE_COUNTER_INTEL)
            iCount++;
    }
    return -5 * iCount;   // 每王牌驻守 -5%，可叠加
}
```
- 效果链路：各城腐败分 = 各城分数 × modifier/100，全国各城同步 -5%×王牌反间谍数。

## 五、平衡备注

- **强度档位**：A/B/D/E 是数值线（平滑），C/G/H/I/K 是战术强化，F/J 是定位能力——整体偏强但可接受，因为晋升门槛（三线成就）已经过滤了多数间谍。
- **H 与 G 联动**：王牌反间谍抓人 `rank*30(90) + 全国叠加`，自己又几乎不死——单个王牌在己方城市近乎"免疫+必杀"，属设计内威慑。
- **I 的 +50**：选举默认 +20，2.5 倍，配合 B 的 16/回合，数值偏高，建议先按 +35~40 试水再回调。
- **K 的 -80%**：购买投票承诺价值打 2 折，配合 J 的 3 票，王牌外交官在议会博弈中极具统治力，符合"外交大师"定位。
- **L 与本地 -100% 叠加**：王牌驻守城市本地腐败已封顶 -100%（与特级相同），L 额外给全国 -5%/王牌。可叠加设计下多城同时挂王牌反间谍可大幅压低全国腐败；但王牌本身极稀有（三线成就），实际叠加数量有限，数值可接受。注意 `-5×N` 与现有本地 `-33/-67/-100` 同段累加，需确认总 modifier 下限（现 `max(0, modifier)`）。

## 六、落地顺序建议

- **一期（机制优先，几乎全零改动+简单判定）**：A、B、C、D、E、G、I、L
- **二期（质变+新成员）**：1 晋升三条件、F、H、K
- **三期（外交模块）**：J（涉议会选票与移民系统，独立排期）
